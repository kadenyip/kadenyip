## `03` / Featured project

### Genetic Algorithm

**Turning random characters into a target phrase—one generation at a time.**

A Python experiment in evolutionary computation. Candidate strings compete through fitness scoring, while selection, crossover, and mutation gradually improve the population until it reaches the target.

| Mechanism | What it does |
| :--- | :--- |
| **Fitness** | Scores characters that match the target in the correct positions |
| **Selection** | Chooses strong candidates to produce the next generation |
| **Elitism** | Preserves the best candidates |
| **Crossover** | Combines genetic information from two parents |
| **Mutation** | Introduces random changes to explore new possibilities |
